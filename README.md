# Real-Time Fraud Detection Pipeline

A local real-time Data Engineering project that processes simulated financial transactions.

## Planned Architecture

Python Producer → Kafka → Flink → ClickHouse → Grafana

## Project Goals

- Generate realistic financial transaction events
- Stream events through Apache Kafka
- Validate and transform events with Apache Flink
- Detect potentially fraudulent transactions
- Store processed data in ClickHouse
- Monitor transaction activity using Grafana

## Technology Stack

- Python
- Apache Kafka
- Apache Flink
- ClickHouse
- Grafana
- Docker and Docker Compose
